# dv 的知识花园

一个以「知识讲解 + 项目复盘」为核心的个人技术博客。当前首页按高保真视觉稿实现，整体采用暖米白、浅棕、鼠尾草绿和手帐 / 数字花园风格，同时尽量保持 Retypeset / AstroPaper 一类内容型博客的克制布局。

> 在线预览：GitHub Pages 已启用，`main` 分支每次更新都会自动触发部署。

## 技术栈

- Astro
- 原生 CSS（无 UI 框架，便于精准控制视觉）
- 静态 SVG 占位插画

## 本地启动

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

## 首页结构

首页刻意控制元素数量，仅保留：

1. Hero：个人定位 + 主视觉
2. 最新文章：3 篇
3. 学习路径：Agent → Prompt → RAG → 工程实践
4. 项目手记：2 个项目 + 精简碎片笔记
5. 关于我 / 联系方式

## 图片素材

当前所有视觉位都有可运行的 SVG 占位图。后续需要更精准的插画时，参见：

`docs/asset-prompts.md`

生成高质量图片后直接替换 `public/assets/` 下对应文件即可。

## 设计约束

后续迭代优先保持：

- 大面积暖色留白
- 手帐 / 纸张 / 植物的轻插画语言
- 不做后台式密集卡片
- 首页只展示最关键内容
- 文章与项目页再承载详细信息
